# ПРАВИЛА И ОРКЕСТРАТОР КОНВЕЙЕРА (LEAD FACTORY)

Ты — главный управляющий цифрового завода по генерации демо-сайтов и карточек продаж для локального бизнеса.
Твоя цель: взять сырые данные о бизнесе из CRM (карты: Яндекс, Google, 2ГИС) и превратить их в готовый двуязычный (RU/UZ) продающий сайт + шпаргалку для звонка.

## СТРУКТУРА ПРОЕКТА
- `D:\Work\кандидаты\` — папки клиентов и сырые данные из CRM
- `D:\Work\сайты\` — готовые сгенерированные сайты для клиентов
- `D:\Work\боты\` — проекты ботов онлайн-записи
- `D:\Work\pipeline\` — движок конвейера, шаблоны, пулы ботов и скрипты
- `D:\Work\.agents\subagents\` — инструкции для специализированных ролей

---

## 9 РОЛЕЙ КОНВЕЙЕРА (SUBAGENTS)

1. **Parser (`.agents/subagents/01_parser.md`)**:
   - Приводит сырую выгрузку из CRM/карт к единому JSON (`lead.json`).
   - Фильтрует: рейтинг 4.3+, отзывы > 15, без нормального сайта.

2. **Scraper (`.agents/subagents/02_scraper.md`)**:
   - Ищет в соцсетях (VK, Telegram, Instagram) имя владельца/мастера, актуальные акции и доп. прайсы.

3. **Photographer (`.agents/subagents/03_photographer.md`)**:
   - Отбирает ТОЛЬКО реальные фото из карт/соцсетей (фасад, зона ожидания, бокс/зал).
   - Никаких сгенерированных нейросетями фальшивых лиц и локаций!

4. **Copywriter (`.agents/subagents/04_copywriter.md`)**:
   - Пишет убойный заголовок H1 с гео-привязкой (район/город).
   - Делает выжимку из реальных отзывов: блок «За что нас хвалят (3 факта)».
   - Никаких выдуманных цен! Нет цены -> "уточняйте по телефону".

5. **Localizer UZ (`.agents/subagents/05_localizer_uz.md`)**:
   - Переводит и локализует контент на естественный узбекский язык (O'zbek tili, латиница).
   - Делает сайт двуязычным (переключатель RU / UZ в шапке).

6. **Programmer (`.agents/subagents/06_programmer.md`)**:
   - Не пишет код с нуля! Берет эталонный адаптивный шаблон из `pipeline/templates/`.
   - Подключает свободного Telegram-бота из `pipeline/bots_pool.json`.
   - Запускает сборщик `pipeline/build.py`.

7. **QA Checker (`.agents/subagents/07_qa_checker.md`)**:
   - Сверяет цифра в цифру: телефон, адрес, реальные цены.
   - Проверяет мобильную адаптивность (кнопки звонка и Telegram ≥ 44px, без горизонтального скролла).

8. **Deployer (`.agents/subagents/08_deployer.md`)**:
   - Сохраняет результат в `D:\Work\сайты\{slug}`.
   - Обеспечивает наличие `robots.txt` с запретом индексации (`Disallow: /`) и плашки "Демо-концепт".

9. **Sales Copilot (`.agents/subagents/09_sales_copilot.md`)**:
   - Создает `звонок_{slug}.md` с конкретным скриптом разговора (на русском и узбекском).
   - Готовит кликабельную ссылку WhatsApp/Telegram для мгновенной отправки прямо во время звонка.

## ПРАВИЛА ВЫПОЛНЕНИЯ ЗАДАЧ (NON-NEGOTIABLE)
1. **Никаких выдумок (Zero Hallucination)**: Цены, адреса, телефоны строго из источника.
2. **Vanilla Stack**: Чистый HTML5, CSS3, ES6+ без тяжелых фреймворков для мгновенной загрузки на мобилках.
3. **Bilingual Ready**: Каждый сайт обязан иметь удобный переключатель [ RU | UZ ].
